# Apna Market Design System

## Visual Guidelines
- **Color Mode**: Light Mode
- **Primary Brand Color**: `#16a34a` (Forest Green - represents freshness, quality, and local organic farms)
- **Primary Hover/Active**: `#15803d`
- **Secondary Accent**: `#22c55e` (Grass Green)
- **Soft Accent / Badges**: `#dcfce7` (Light mint background with `#15803d` text)
- **Background Primary**: `#f8fafb` (A clean, airy, slightly off-white background)
- **Background Secondary**: `#ffffff` (Pure white for cards, list items, and interactive containers)
- **Text Color Primary**: `#0f172a` (Slate-900 - dark charcoal for high readability)
- **Text Color Secondary**: `#475569` (Slate-700 - medium slate for labels, helper text, and descriptions)
- **Text Muted**: `#64748b` (Slate-500)
- **Borders**: `#e2e8f0` (Thin, light borders to define structural elements without visual clutter)
- **Roundness**: `12px` (Rounded corners for friendly, modern aesthetic)
- **Shadows**: Soft, high-dispersion box shadows (`0 8px 30px rgba(0, 0, 0, 0.05)`)
- **Typography**: 
  - Headline Font: `Outfit` (Modern, geometric feel)
  - Body Font: `Plus Jakarta Sans` (Clean, highly legible neo-grotesque)
